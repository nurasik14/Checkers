# Checkers

[English](README.md) | Русский

Современная веб-платформа для игры в шашки онлайн с мультиплеером в реальном времени, профилями игроков и историей партий.

## Короткое описание продукта

Это полноценная онлайн-платформа для шашек, а не просто статическая демо-игра.

**Для кого проект:**
- Для игроков, которые хотят быстро играть в шашки с друзьями по сети.

**Почему это ценно:**
- Реальный мультиплеерный сервис, где партии сохраняются и синхронизируются в реальном времени.
- Встроенная авторизация, профиль игрока и история матчей делают проект готовым к развитию.
- Архитектура на чистом JavaScript + Firebase упрощает расширение (новые режимы, AI, монетизация).

## Что уже реализовано

- Онлайн-лобби для создания, подключения и просмотра игр.
- Авторизация через Google и гостевой режим.
- Создание новой партии и вход по Game ID.
- Режим зрителя для наблюдения за активными матчами.
- Базовые правила шашек: диагональные ходы, взятия, превращение в дамку, обязательные взятия.
- Встроенный чат во время партии.
- Быстрый возврат в лобби и автоматическое завершение партии при отключении соперника.
- Серверная логика на Firebase Cloud Functions: проверка ходов, защита от мошенничества, сохранение результатов.
- Профиль игрока с историей партий, статистикой побед/поражений и цветом аватара.
- Два игровых режима: Classic и Atari.
- Блок «Go Pro» в интерфейсе как прототип монетизации.

## Основные возможности

- Лобби со слотами игр и статусом подключения.
- Кнопка «Create new game» и поле для ввода Game ID.
- Режим наблюдения («Spectate»).
- Секция живого состояния матча (чей ход, режим, количество зрителей).
- Кнопки «Surrender» и «Lobby» для быстрого выхода.
- Подсказка легальных ходов через «Show moves».
- Чат с аватаром и временем сообщений.
- Профиль с историей и статистикой.
- Поддержка локальной разработки через Firebase Emulator Suite.

## Как это устроено

### Фронтенд

- Чистый HTML/CSS/JavaScript в папке `public/`.
- Модульная структура: `main.js`, `game.js`, `ui.js`, `engine.js`, `module.js`, `auth.js`, `firebase.js`.
- Интерфейс рендерит доску 8×8, подсвечивает ходы и обновляет состояние игры/чата в реальном времени.
- `engine.js` реализует правила шашек и валидацию допустимых ходов.
- `firebase.js` настраивает Firebase Realtime Database, Authentication и Functions.

### Бэкенд

- Firebase Realtime Database хранит состояние игр, игроков, чат и статистику.
- Firebase Auth отвечает за авторизацию и привязку действий к игрокам.
- Cloud Functions в `functions/index.js` проверяют ходы, создают игры, обрабатывают сдачу, отключения и записывают историю матчей.
- Планировщик очищает устаревшие завершённые партии.

### Архитектура

- Клиент подписывается на `games/{gameId}` для получения обновлений в реальном времени.
- Игровые действия проходят через безопасные серверные валидаторы (`createGame`, `makeMove`, `surrenderGame`, `claimWin` и обработчики зрителей/сессий).
- Для надёжного обновления статуса используется Firebase `onDisconnect`.
- История и статистика игроков сохраняются в `players/{playerId}`.

## Технологический стек

- HTML / CSS / JavaScript
- Firebase Realtime Database
- Firebase Authentication
- Firebase Cloud Functions
- Firebase Emulator Suite (для локальной разработки)

## Быстрый старт

1. Откройте проект в VS Code.
2. Выполните `npm install` в папке `functions`.
3. Настройте Firebase-проект или локальные эмуляторы.
4. Запустите фронтенд из `public/` через любой локальный веб-сервер.
5. Откройте приложение и войдите через Google или как гость.

## Почему проект выделяется

- Это не локальная симуляция, а полноценный онлайн-сервис игры.
- Есть продуктовая основа: профили, история матчей, чат.
- Ориентация на удержание: быстрые реванши, повторный вход, видимый прогресс.
